# AETHER RAG

A local, private **Retrieval-Augmented Generation** desktop app. Upload your
documents (PDF, DOCX, TXT, images, or a URL), and ask questions — answers are
generated by an LLM and grounded in your own files with inline citations.
Everything runs on your machine; your documents never leave it.

- **Backend** — FastAPI (Python) RAG pipeline: ingest → chunk → embed → hybrid
  retrieve (BM25 + vector) → optional rerank → LLM answer with citations.
- **Frontend** — Next.js UI, packaged as an Electron desktop app.
- **Vector store** — LanceDB (embedded, on-disk). **LLM** — OpenRouter (hosted
  free models) or Ollama (fully local).

---

## Install (end users)

Run the installer and launch **AETHER RAG** from the Start menu:

```
dist_installer/AETHER RAG-Setup-<version>.exe
```

It's unsigned, so Windows SmartScreen shows a one-time "Unknown publisher"
prompt → **More info → Run anyway**. This is expected.

**First run:** open **Settings → API Credentials** and paste an OpenRouter API
key (free at <https://openrouter.ai/keys>) to enable answers. The key is stored
locally and never bundled into the app. The first launch also downloads the
embedding model (~64 MB) once, so it needs internet that first time.

> Tip: to confirm you're on the latest build, the sidebar shows the version
> (e.g. `v0.1.1 • Beta`).

## Run from source (developers)

**Prerequisites:** Python 3.11, Node.js 20+, and (optional) Ollama for local LLM.

```bash
# 1. Backend
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy .env.example .env          # then edit values (see Configuration)

# 2. Frontend
cd ../frontend
npm install
```

**Start everything** (backend on :8000, frontend on :3000, opens the browser):

```
scripts\StartRAG.bat
```

Or run the pieces manually:

```bash
# backend
cd backend && venv\Scripts\python -m uvicorn app.main:app --port 8000
# frontend (separate terminal)
cd frontend && npm run dev
```

Launch the **Electron desktop app** in dev instead: `scripts\StartApp.bat`
(or `npm run app` in `frontend/`). Stop the dev stack with
`scripts\StopRAG.bat`.

## Configuration

Backend config lives in `backend/.env` (see `backend/.env.example` for all
keys). The important ones:

| Key | Purpose | Default |
|-----|---------|---------|
| `LLM_PROVIDER` | `openrouter` (hosted) or `ollama` (local) | `ollama` |
| `OPENROUTER_API_KEY` | required if provider is `openrouter` | — |
| `OPENROUTER_MODEL` | hosted model id | a free Llama model |
| `OLLAMA_BASE_URL` / `LLM_MODEL` | local Ollama endpoint + model | `:11434` |
| `DATABASE_URL` | Postgres URL; falls back to SQLite if unreachable | Postgres |
| `REDIS_URL` | Redis URL; falls back to in-memory if unreachable | `:6379` |
| `LANCE_URI` | on-disk vector store path | `./vector_store` |
| `USE_RERANKER` | enable cross-encoder reranking | `false` |

Provider and model can also be switched at runtime in **Settings** (no restart).
Changing `.env` values **does** require a backend restart.

### Service degradation (nothing is a hard dependency)

| Service | If unavailable |
|---------|----------------|
| PostgreSQL | Falls back to local **SQLite** (`backend/sql_app.db`) |
| Redis | Falls back to **in-memory** chat memory |
| Ollama | LLM features off until an OpenRouter key is set (or Ollama runs) |

## Build the installer

Two steps — freeze the backend, then package the app:

```bash
# 1. Freeze the FastAPI backend (only needed when backend code changes)
cd backend/packaging
..\venv_pkg\Scripts\pyinstaller.exe aetherrag-backend.spec --noconfirm --clean

# 2. Build the frontend + Windows installer
cd ../../frontend
npm run dist
```

Output: `dist_installer/AETHER RAG-Setup-<version>.exe`. The full build takes
~15 min (the PyInstaller freeze and NSIS compression are the slow parts); if
only frontend changed, skip step 1 (~10 min). Bump `frontend/package.json`
`version` (and the sidebar label in `Sidebar.tsx`) so new installs are
distinguishable.

> Code signing is intentionally off (no paid cert). To sign, set `CSC_LINK`
> and `CSC_KEY_PASSWORD` before `npm run dist` — no code changes needed.

## Password recovery

There's **no email** in this offline app, so a forgotten password is recovered
by answering a **security question** set at signup. Existing accounts can set
one in **Settings → Profile**. Changing it requires the current password.
